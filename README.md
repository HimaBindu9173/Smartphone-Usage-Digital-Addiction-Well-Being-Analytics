# 📱 Smartphone Usage, Digital Addiction & Well-Being Analytics

## 📌 About

This project uses **Power BI** to analyze smartphone usage, digital addiction, and well-being patterns.

## 🎯 Objectives

* Analyze smartphone and screen-time usage.
* Identify digital addiction patterns.
* Study the relationship between smartphone usage, sleep, and well-being.
* Present insights through interactive visualizations.

## 🛠️ Tools

* Power BI
* Power Query
* DAX

## 📊 Outcome

An interactive Power BI dashboard that converts smartphone usage data into **clear and meaningful insights**.
